WS-A. One unified bottom-docked instruction bar replaces today's single-send bar. A full-width text input sits above a control row: attach + model selector + web-search toggle on the left, Ask (ghost) + the context-appropriate primary action on the right. Which button is dark-filled (primary) — and therefore what plain Enter submits — changes with context; ⌘/Ctrl+Enter always reaches the other one.

(a) Default — Build primary
rate-limit.middleware.ts

Enter → Build, a paid sandbox run. ⌘/Ctrl+Enter (or the Ask button) → Ask, a free LLM call with no sandbox spend.

(b) Ask variant — asking about a commit, Ask primary
Asking about b6537cd
Ask a question about this commit…

Enter → Ask, free — answers from b6537cd, no sandbox spend. ⌘/Ctrl+Enter → Build if you want a new paid run instead. The ✕ clears the commit context without losing what you typed.

(c) Research node — no sandbox, Go deeper / Ask
Ask a question, or go deeper on this section…

A research (learn) node has no sandbox to spawn — Go deeper and Ask are both free LLM calls, so Enter is safe either way. Model and web-search still apply to the branch call.
