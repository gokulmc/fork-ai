Round 2 — Distributed learn-node layout

Updates the git-graph column allocator's rule for hanging (Learn) nodes: instead of a single lane offset to the right of an anchor, a code node's Learn children are spread and centered under that node's own x, offset straight down — visually distinct from the trunk's strict vertical fall, and no longer competing for the same right-hand space forks use. CODE still falls straight down its column (parent x = child x); BRANCH still forks to a new column at the SAME row as its fork commit, with a strict horizontal arrow. Edges stay colored (branch = green, fork; merge = violet); nodes are grey (Round 2). This documents the spec for layoutGitGraph.ts's hang-placement function. (WS-M · #221)
