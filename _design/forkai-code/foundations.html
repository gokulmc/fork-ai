Foundations

New tokens layered on top of fork.ai's existing design language for the coding-agent surface: kind accents, the commit pill, git-graph lanes, diff colors, and the agent-log panel. Base tokens (bg / ink / line / accent / shadow / radius) are unchanged — see tokens.css.

Kind accents

Desaturated — tint a card's left border, kicker text, and pill; never the whole card surface.
